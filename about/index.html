MEET JULIE

Hi, I'm Julie.

I’m a software engineer working at Google, based in NYC.

Currently, I’m the Uber Tech Lead for the Google Cloud Software Development Kit (SDK). My team builds client libraries and command-line tools to create seamless, end-to-end developer experiences, enabling developers to easily interact with Google Cloud products across various programming languages.

Previously, I led the Go Security team, where our mission was to make Go the best programming language for building secure and reliable software. Before that, I was the Tech Lead for the Go Web and Discovery team, spearheading the development of Go’s package management platform, and leading projects like the creation of pkg.go.dev.

Before joining Google, I worked as the Engineering Manager for the Catalog Platform team at Spring, an e-commerce marketplace now part of ShopRunner.

I am also a proud alum of the Recurse Center (#nevergraduate) and passionate about supporting rising technical leaders, helping them build confidence, and find joy in their work. I believe that by empowering each other, we can create software that makes life better for everyone. I write about my own experiences and insights at theviewfromjq.com.

If you’d like to connect, feel free to reach out!
